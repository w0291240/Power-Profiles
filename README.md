**macOS Power Profiles**


**This is a project to create an application for macOS that will allow a user to set power profiles.**

The goal is to create a visually cohesive application, in which the user can specify what battery-life related settings are turned on or off, or adjusted, when connecting to or disconnecting from wall power.

Another further goal, provided this works out satisfactorily, is to set the same options for user-specified power curves.

For example, the user may define a rule that, if the battery reaches 50%, refresh rate will change to 60hz.


This is my personal largest current gripe with my MacBook Pro, mainly with the brightness dipping to half when removed from wall power.

**My project aims to solve this.**
